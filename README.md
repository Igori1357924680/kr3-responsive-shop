# PlayTable — магазин гаджетов и аксессуаров

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина гаджетов и аксессуаров PlayTable.

## Используемые технологии

- HTML5 (семантическая разметка)
- CSS3 (переменные, Flexbox, Grid, позиционирование)
- БЭМ-именование классов
- Минимальный JavaScript для модального окна и кнопки «Наверх»

## Обязательные страницы

- `index.html` — главная: hero-блок, преимущества, популярные товары, контакты (якорные ссылки)
- `catalog.html` — каталог: сетка карточек, категории, sticky-фильтр, статический блок
- `product.html` — карточка товара: изображение, описание, характеристики, цена, кнопка заявки, модальное окно
- `order.html` — форма оформления заявки
- `contacts.html` — контактная информация и форма обратной связи

## Самостоятельные доработки

- Фиксированная кнопка «Наверх» с плавной прокруткой
- Sticky-фильтр категорий в каталоге
- Хлебные крошки на страницах каталога и товара
- Бейджи «Новинка», «Хит», «Скидка» через БЭМ-модификаторы
- Модальное окно заявки через `<dialog>`
- Уникальные `title` и `meta description` на каждой странице

## Как посмотреть проект

1. Открыть ссылку GitHub Pages.
2. Или склонировать репозиторий и открыть `index.html` в браузере.
